# Media Player Platform

**Plataforma de reprodução multimídia e exibição de conteúdo publicitário.**

## Sobre o projeto

O Media Player Platform é uma plataforma Android desenvolvida para transformar dispositivos móveis e tablets em pontos de reprodução audiovisual e divulgação publicitária.

O projeto foi estruturado para permitir a utilização de diferentes conteúdos, campanhas, marcas e aplicações, sem ficar limitado a um único anunciante.

## Funcionalidades

- Reprodução de vídeos MP4.
- Reprodução contínua (Loop).
- Suporte a conteúdo offline.
- Exibição de banners publicitários.
- Espaços para divulgação de marcas e serviços.
- Integração com QR Codes.
- Interface adaptável a diferentes dispositivos.
- Distribuição de aplicativos Android (APK).

## Objetivo

Criar uma estrutura flexível para reprodução de vídeos e publicidade digital, permitindo futuras expansões e integração de novos formatos de anúncios.

## Tecnologias

- Android
- APK
- Reprodução multimídia
- Armazenamento local
- Interface gráfica adaptável
